Pawlet — macOS 13 or later, Apple silicon and Intel

Drag Pawlet.app to Applications, then open it from Applications.
The paw in the menu bar opens your library and settings.
Closing the library keeps the minis running; choose Quit from the paw menu to exit.

Mochi and Paris are included. Idle motion is off by default.
Import one or more .petpack files, Codex mini ZIPs/folders, or complete sprite sheets.
Use Command-click or Shift-click to select multiple minis; valid imports are kept if another fails.
Hover to greet, click to wave, double-click to jump, drag to move, or right-click for actions.
Enabled idle/activity loops rest ten seconds between plays by default.
Hover re-entry restarts the chosen reaction immediately, independently of that interval.
Settings lets you adjust the interval, disable greetings, or shrink minis to 25%.
Minis folder opens the whole library in Finder; Share exports a pack, ZIP or Codex folder.
Create opens a prepared Codex prompt; Codex is optional for running existing minis.

No Git, Xcode, npm, Python or Codex is needed to install or run this download.

This build is ad-hoc signed and not notarized by Apple. macOS may block it on
first launch because the developer cannot be verified. If you trust the download:
1. Move Pawlet.app to Applications and try opening it once.
2. Open System Settings → Privacy & Security.
3. Scroll to the Pawlet message, click Open Anyway, then confirm Open.
Apple's instructions: https://support.apple.com/en-us/102445
Managed Macs may prevent this exception.

To update, quit Pawlet and replace the app in Applications with the new download.
Your minis and settings stay in your user library.

Source and contribution instructions are in the Pawlet source repository.
This is an independent app, not an official OpenAI product.

Minis folder in the library toolbar opens all installed minis.
Choose an animation in a mini’s preview to loop it; pause or step through its frames.
On hover sets this mini’s greeting. Settings has the default for other minis.
Size changes only this mini; the reset button uses the default size from Settings.

Each companion card has Show mini / Hide mini for one-click desktop visibility.

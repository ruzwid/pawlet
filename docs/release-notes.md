Download the **Pawlet DMG** under Assets, open it, and drag **Pawlet.app** to **Applications**. The ZIP is an alternative: expand it and move Pawlet.app to Applications.

Requires **macOS 13 or later**. One download supports **Apple silicon and Intel Macs**. No Git, Xcode, npm, Python, Codex or Apple Developer account is needed to run the app. Mochi and Paris are included; existing minis run offline.

This build is **ad-hoc signed and not notarized by Apple**. On first launch, macOS may block it because the developer cannot be verified. If you trust this download:

1. Move Pawlet.app to Applications and try opening it once.
2. Open **System Settings → Privacy & Security**.
3. Scroll to the message about Pawlet and click **Open Anyway**, then confirm **Open**.

See [Apple's instructions](https://support.apple.com/en-us/102445) for details. Managed Macs may prevent this exception. Signing and notarization will be added when an Apple Developer Program membership is available.

To update, quit Pawlet and replace the app in Applications with the new download. Your minis and settings stay in your user library.

`SHA256SUMS.txt` contains checksums for both downloads. Choose the DMG or app ZIP under **Assets**; GitHub's automatic **Source code** archives contain the source, not the built app.
